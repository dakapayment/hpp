Panduan Setup Database Google Sheet & GitHub

Gratis 100%
1

Buat Google Sheet & Buka Apps Script:

Buka sheets.new → Klik menu Ekstensi (Extensions) → Apps Script.

2

Salin Script Backend Google Sheet:

Hapus kode bawaan di editor Apps Script, lalu tempel kode berikut:

Tersalin!
3

Deploy sebagai Web App:

Klik tombol biru Terapkan (Deploy) → Kelola Penerepan Baru (New deployment) → Pilih jenis Aplikasi Web (Web app).

  • Jalankan sebagai: Saya (email Anda)
  • Siapa yang memiliki akses: Siapa saja (Anyone) ← Sangat penting!
4

Salin URL & Masukkan ke Aplikasi:

Salin URL Web App yang berakhiran /exec, tempel ke input URL di atas, lalu klik Simpan & Hubungkan.

★

Hosting di GitHub Pages (Akses Semua Device):

Buat repository baru di GitHub → upload file index.html ini → buka Settings > Pages > Deploy from Branch (main). Buka tautan GitHub Pages di HP atau laptop Anda untuk mengakses data yang tersinkron otomatis!
